Command line args:
------------------
-help                   show this help
-startup                startup script to run, default is: home:bin/startup.tcl
-sceneserver            scene server to use
-scriptserver           script server to use
-input                  input binding script to run, default is: home:bin/stdinput.tcl
-view                   data to load and view with the lighting setup specified (either -stage or the default)
-stage                  light stage to load, default is: home:bin/stdlight.tcl
-fullscreen             if present, then nviewer will go fullscreen
-alwaysontop            present the window will be allways on top
-w                      width of window to open (default: 640)
-h                      height of window to open (default: 480)
-x                      the x position of the window (default: 0)
-y                      y position of the window (default: 0)
-connect                if presents, client will try to connect to specified by "ip:port" server 
-pass					specifies server password (optional)
-login					if presents, the application will try to login to this account "username,password"
-safemode               runs in safe mode
-projdir                the optional project directory (assigns it to the projdir: alias, for use in the user's scripts)

-noautoupdate
