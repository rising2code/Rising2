Server Admin Command List:
sudo help
    this help
sudo admin [admin_password]
    login to admin mode.
sudo kick [user_name] [kick_reason]
    kick specific user (reason is optional).
sudo ban [user_name] [minutes] [opt. ban_reason]
    ban specific player (0-minutes for permanent ban)
sudo unban [user_name]
    unban specific player.
sudo warn [user_name]
    warn specific player.
sudo maxwarn [number_of_warnings]
    set max number of warnings.
sudo banlist
    view list of banned players.
sudo userlist
    view list of connected players.
sudo pass
    set password protection for server.
sudo nopass
    remove password protection from the server
sudo end_round
    end playing session.
sudo friendlyfire [1/0]
    enable friendly fire.
sudo autoteambalance [1/0]
    enable team auto-balance.
sudo tklimit [number_of_kills]
    change team kill tolerance level.
sudo hostname [new_host_name]
    change server name.
sudo timelimit [minutes]
    change session time.
sudo say_all [message]
    send admin message to all players.
sudo say_player [user_name] [message]
    send admin message to specific player.
sudo map?
    view levels list.
sudo map [mission_type] [level_name]
    change map by level name.
    # Yoni note: mission_type is string, from "sudo map?" like conquest
sudo map# [mission_type] [level_number]
    change map by level list index.
sudo pause
    pause session.
sudo unpause
    unpause session.
